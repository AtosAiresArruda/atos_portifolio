OCR → JSON com gemma-4-E2B-itOCR → JSON with gemma-4-E2B-it

Estou fazendo fine-tuning de um modelo com módulo de visão para ler documentos digitalizados e devolver JSON estruturado. A tese: chegar ao mesmo resultado dos grandes modelos de mercado e open-source consumindo menos processamento. I'm fine-tuning a vision-language model to read scanned documents and return structured JSON. The thesis: match the output of large commercial and open-source models while using less compute.

A tarefaThe task

O modelo recebe a imagem de um documento e precisa devolver os campos dele num JSON que outro sistema consiga usar direto. The model gets an image of a document and has to return its fields as JSON that another system can use directly.

EtapasStages

  1. AgoraNow

    Prova de conceito com QLoRAProof of concept with QLoRA

    O QLoRA treina adaptadores pequenos sobre o modelo quantizado, o que permite testar a ideia com pouca memória de GPU.QLoRA trains small adapters on top of the quantized model, which lets me test the idea with little GPU memory.
